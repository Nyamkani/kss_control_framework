## 기준 궤적과 비교 방법

로봇 좌표계 속도 `(u,v,w)`가 일정한 운동의 해석해를 사용했습니다. 초기 방향을 `a`, 시간을 `t`라 할 때 `w != 0`이면:

```
X = (u sin(wt) + v (cos(wt)-1)) / w
Y = (u (1-cos(wt)) + v sin(wt)) / w
x = cos(a) X - sin(a) Y
y = sin(a) X + cos(a) Y
yaw = atan2(sin(a+wt), cos(a+wt))
vx = u, vy = v, wz = w
```

`w == 0`이면 `X=ut, Y=vt`입니다. 상대 모드 기준은 `a=0`, 절대 모드는 센서의 초기 방향을 사용합니다. 센서 방향은 각도 경계 시나리오에서 179도, 나머지에서 70도입니다. 기준 생성에는 필터의 `Transition`, `Predict`, `Wrap`을 호출하지 않습니다. 초기 기준 궤적과 센서 측정은 같은 해석해에서 생성합니다.

측정은 시각순으로 즉시 전달하며 같은 시각에는 방위각→바퀴→각속도 순서입니다. 이는 절대 모드의 최초 방향 설정을 먼저 완료하기 위한 순서입니다. 전송 지연·잡음·바이어스는 추가하지 않았습니다. 전체 시간 8초, 비교 간격 10밀리초, 각 실행당 801개 표본입니다.

공백은 2초에 시작합니다. 바퀴 우선 복구는 바퀴 4초, 각속도 4.2초, 방위각 4.4초부터 수신합니다. 관성센서 우선 복구는 각속도·방위각 4초, 바퀴 4.4초부터 수신합니다. 실제 기준 운동은 공백 중에도 계속됩니다. 양쪽 순서 모두 4.4초에 복구하는지, 복구 완료 전 위치를 적분하지 않는지 검사합니다. 마지막 공백 전 측정은 1.98초이고 유효기간 만료는 2.48초입니다.

오차는 추정값을 현재 기준 시각과 비교합니다. 새 측정이 없는 10밀리초 중간 시점에는 마지막 추정 상태를 그대로 비교하므로 상태 시각 지연 오차도 포함됩니다. 공백에서는 `valid=false` 상태도 최대 오차에 포함합니다. 실제 필터 상태 시각과 유효성은 원시 기록에 따로 남깁니다. 방위각 오차는 `atan2(sin(차이), cos(차이))`의 절댓값입니다. 아래 0.000000은 여섯 자리 반올림 결과입니다.

## 판정 기준과 해석

연속 입력의 최대 성분별 오차 기준은 위치 각각 0.1m 미만, 방위각 0.08rad 미만, 선속도 각각 0.05m/s 미만, 각속도 0.03rad/s 미만입니다. 정지 시나리오는 모든 성분의 최대 오차 1e-10 미만을 요구합니다. 이는 합성 회귀 판정 기준이며 실기 정확도 요구사항이나 검증된 센서 사양이 아닙니다.

이동 공백은 위치 정확도 통과 판정이 아닙니다. 올바른 중단·순차 복구와 누락 이동에 따른 잔여 위치 오차(2.3~2.6m)를 확인하는 정책 검증입니다. 약 2.42초의 이동을 누적하지 않으므로 복구 후 약 2.42m의 위치 오차가 남습니다. 남은 오차는 이 시험에서 발견된 새 구현 결함이 아니라, 위치 관측 없이 공백 적분을 생략하는 기존 한계입니다. 공백 중 속도 0은 실제 정지 측정이 아니므로 무효 구간의 최대 속도 오차는 1m/s입니다.

공분산은 구현의 `Healthy()`를 사용하지 않고 모든 원소의 유한성, 대칭 오차 1e-10 미만, 별도로 작성한 확장 정밀도 촐레스키 분해의 양수 대각 조건을 검사했습니다. 매 측정 수용 후와 매 비교 시각에 실행했습니다. Q/R 실측 조정, 오차 분포와 공분산의 통계적 일치, 센서 상관관계 및 실제 로봇 정확도를 검증한 것은 아닙니다. 측정 주기 차이는 포함하지만 전달 순서 역전이나 실제 지연은 포함하지 않습니다.
