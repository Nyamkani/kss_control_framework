# KCF Core v5.6.2

KCF Core v5.6.2 extends Gateway observability, remote Topic
exposure, Action status observation, diagnostics, and CLI support.

## Changes

- Gateway remote Publisher exposure with explicit opt-out policy
- Remote Action Event / Scheduled Poll status observation
- Topic rate, freshness, and network diagnostics improvements
- Supervisor diagnostics and read-only KCF CLI
- Opt-in per-Topic timestamp tolerance (default OFF)
- Gateway systemd configuration and regression tests
- Native Debian packaging for Ubuntu 24.04 / 26.04,
  AMD64 / ARM64

## Compatibility

- FrameworkVersion: 5.6.2
- Network Protocol major version: unchanged
- Existing Topic latest-only / no-catch-up behavior retained
- Applications using EXACT_FRAMEWORK_VERSION must account for
  the FrameworkVersion change.
- Rebuild statically linked applications when updating Core.

## Verification

- Core CI: Gateway, Topic, Action, Diagnostics and CLI
- Native Release DEB builds for four Ubuntu/architecture combinations
- Previous physical validation: Orange Pi 5+ with UGV02 over Wi-Fi

## Known limitations

- Gateway restart / Discovery session recovery may take approximately
  240 seconds or longer in observed Wi-Fi conditions (Core Issue #6).
- Remote Topic reconnection in Tools may require manual resubscription.
- Sustained 100 Hz delivery is not guaranteed by all tested scenarios.
- Timestamp tolerance does not provide guaranteed throughput improvement.
- Per-platform packaging success does not imply physical runtime
  validation on every supported environment.

## Debian packages

- Ubuntu 24.04 AMD64
- Ubuntu 24.04 ARM64
- Ubuntu 26.04 AMD64
- Ubuntu 26.04 ARM64

Each package includes the KCF runtime and development SDK.
Verify SHA256SUMS before installing.
